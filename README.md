# HerbVision – AI-Based Medicinal Plant Identification

HerbVision is a Flask-based web application that uses Deep Learning and Computer Vision techniques to identify medicinal plants from leaf images.

## Features

* AI-powered medicinal plant recognition
* Identification of 30 medicinal plant species
* Plant information display including:

  * Medicinal uses
  * Ayurvedic name
  * Family
  * Habitat
  * Dosage information
* Simple and user-friendly web interface
* Flask backend with TensorFlow/Keras model

## Technologies Used

* Python
* Flask
* TensorFlow / Keras
* OpenCV
* HTML
* CSS

## Dataset

The model was trained on a medicinal plant image dataset containing 30 classes of medicinal plants.

## Installation

```bash
pip install -r requirements.txt
python app.pyx
```
